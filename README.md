# 웹게임프로젝트

## 개요
- 유니티6 LTS를 사용한 웹게임 개발 프로젝트입니다.   
- 게임은 웹브라우저에서 URP + 웹소켓 기반 실시간 서버를 만들어 멀티플레이가 가능하게 구현할 계획입니다.      
- 포트폴리오 겸 인디개발 프로젝트로 생각하고 작업하고 있습니다.   


## 프로젝트 기반
- Unity6.0 LTS
- JSON.NET (유니티 패키지)
- Crockhead.Unity (자작 유니티 패키지)
